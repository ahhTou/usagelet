# usagelet

> 开发中 · 2026-10-18 · 尚未发布可运行版本

参考 [ccusage](https://github.com/ccusage/ccusage)，使用 TypeScript / JavaScript 重构其中与本机 Agent 用量采集、统计有关的部分功能，最终交付一个可下载后直接运行的 `usagelet.mjs`。

目标是在安装兼容 Node.js 的环境中，无需安装 usagelet 的 npm 包、无需在使用端编译或打包，即可读取本机日志、汇总用量并输出统计结果。尽量只依赖 Node.js 内置模块，降低跨平台运行成本；不是浏览器脚本，也不要求运行环境安装 Bun。

**平台验证范围：目前仅以 macOS 为验证环境，其他环境尚未测试；单脚本交付不代表已经验证所有平台。** 最低 Node.js 版本将在日志、SQLite 和 Zstd 能力验证后确定。

## 初步功能

- 自动发现各工具的本机数据源，支持显式指定路径。
- 以日期、Agent、原始模型标识汇总输入、输出及可获得的缓存 token 计数。
- 处理重复日志、累计计数、会话恢复和压缩归档，保证统计口径可解释、可验证。
- 输出供人阅读的简洁汇总，以及供程序使用的 JSON；缺失字段不冒充真实零值。
- 与 `ahhtou.wang` 用量同步协议衔接，仅上传汇总统计，不上传对话原文。

首期不追求复制 ccusage 的全部命令和展示功能。成本估算、其他平台支持等能力，待数据来源与统计正确性稳定后再确定范围。

## 交付方式

计划发布单个 `usagelet.mjs`，下载到本机后通过 `node usagelet.mjs` 执行。当前仓库只有项目说明与开发计划，尚无脚本、下载地址或可用命令。

允许开发阶段使用 TypeScript 和必要的开发工具；使用端只接收单个 JS 文件，不安装运行依赖、不下载平台专用二进制。发布产物的生成方式将在实现时确定。
